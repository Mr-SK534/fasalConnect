🎨 Frontend Stack (React SPA Ecosystem)

⚛️ React v19.2.8

Core UI framework providing component-based interactive user interfaces with Concurrent Rendering and Context API for global state management.

Primary Role: Single-Page Application (SPA) component architecture.
⚡ Vite v8.2.2

Next-generation frontend tooling providing lightning-fast HMR (Hot Module Replacement) and optimized Rollup production bundling.

Primary Role: Development server, ESM bundler, & asset compiler.
🎨 Tailwind CSS v4.3.3

Utility-first CSS framework coupled with @tailwindcss/vite plugin, enabling glassmorphic cards, emerald responsive themes, and micro-interactions.

Primary Role: Design system, responsive layouts, & light/dark styling.
🗺️ React Leaflet & Leaflet.js v5.0.0 / v1.9.4

Interactive mapping engine powered by OpenStreetMap tiles for farm pickup coordinates, buyer delivery locations, and public cold storage hubs.

Primary Role: Geospatial routing maps & farm location rendering.
📊 Recharts v3.10.1

Composable charting library built with SVG components, rendering AI demand forecasts, APMC Mandi rate comparisons, and revenue dashboards.

Primary Role: Time-series graphs & financial data visualization.
🌐 i18next & react-i18next v26.4.1 / v17.0.13

Internationalization framework delivering complete multi-lingual support (English, Hindi, Marathi, Tamil) with dynamic language switching.

Primary Role: Multi-language localization for vernacular farmers.
🧭 React Router DOM v7.18.3

Client-side declarative routing system featuring RoleGuard route protection and multi-step buyer checkout flows.

Primary Role: SPA navigation & role-based route security.
📦 Axios v1.20.0

Promise-based HTTP client equipped with custom request/response interceptors for automatic JWT authentication header injection.

Primary Role: REST API communication & token refresh interceptors.
🧊 Three.js & React Three Fiber v0.185.1 / v9.7.0

WebGL 3D graphics renderer enabling 3D crop growth visualization and interactive produce quality inspectors.

Primary Role: 3D produce & farm visualizer components.

⚡ Backend Stack (.NET 10 ASP.NET Core API)

🖥️ ASP.NET Core Web API .NET 10.0

High-throughput RESTful Web API framework written in C#, delivering controller endpoints, middleware pipelines, and dependency injection.

Primary Role: Core backend business logic & RESTful endpoints.
🗄️ Entity Framework Core 10 v10.0.11

Object-Relational Mapper (ORM) optimized with selective LINQ projections (excluding heavy BLOB columns) and automated migration handling.

Primary Role: Database access layer & Entity modeling.
🐘 PostgreSQL & Npgsql v10.0.3 Provider

Enterprise open-source relational database storing transactional orders, escrow ledgers, product catalogs, and spatial farm locations.

Primary Role: Relational persistent database.
🔑 JWT Bearer Authentication v10.0.11

Stateless authentication using HMAC-SHA256 tokens with claims-based Role-Based Access Control (RBAC across 8 user roles).

Primary Role: User authentication & security authorization.
🔒 BCrypt.Net-Next v4.2.0

Adaptive key-derivation password hashing algorithm protecting user credentials against dictionary & rainbow table attacks.

Primary Role: Salted password hashing & verification.
📖 Swashbuckle OpenAPI v10.2.3

Automated Swagger UI documentation and OpenAPI specification generator for testing and inspecting REST endpoint contracts.

Primary Role: Interactive API documentation & client generation.

🧠 AI, Machine Learning & Optimization Engines

📈 Microsoft ML.NET Time-Series v5.0.0

Machine Learning engine implementing Singular Spectrum Analysis (SSA) for crop demand forecasting, trend decomposition, and Transfer Learning across unlisted crop categories.

Primary Role: 30-Day Multi-Crop Demand Forecasting Model.
🚚 Google OR-Tools v9.15.6755

Combinatorial optimization solver executing Vehicle Routing Problem with Time Windows (VRPTW) to aggregate multi-farmer crop pickups into optimal logistics routes.

Primary Role: Multi-stop route optimization & vehicle assignment.
📐 Haversine Geo-Distance Matrix Custom C# Utility

Great-circle spherical trigonometry solver with road tortuosity factor calibration (\(\tau = 1.30\)) for accurate travel time and freight cost calculations.

Primary Role: Kilometric distance & logistics pricing engine.

💳 Financial, Payments & Communication Stack

💰 Razorpay Escrow SDK v3.3.2

Financial payment gateway handling UPI, Netbanking, Cards, automated escrow holding, and automated bank payouts to farmers upon delivery verification.

Primary Role: Buyer checkout & direct farmer escrow payout.
📞 Twilio Communications v8.0.0

Automated IVR (Interactive Voice Response) toll-free phone booking system and SMS dispatch engine tailored for internet-less rural farmers.

Primary Role: Phone-less voice booking & SMS notifications.
🏛️ Agmarknet APMC Mandi Rates Govt Benchmark Service

Integration layer fetching official Government APMC Mandi rates (Min, Modal, Max) to provide farmers real-time direct selling price comparison advisories.

Primary Role: Real-time APMC Mandi benchmark price feed.
