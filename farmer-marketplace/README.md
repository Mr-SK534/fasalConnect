# Farmer Marketplace — Team Zenith (SIH Project)

A direct farmer-to-consumer marketplace with demand forecasting, route optimization, and split payments.

## Required Versions

| Tool | Version | Why |
|---|---|---|
| Python | **3.12.x** | Newer versions (3.13+/3.14) don't yet have stable wheels for pandas/psycopg2/Prophet — see `.python-version` |
| Node.js | **20.x** | See `.nvmrc` |
| PostgreSQL | Any recent version (hosted via Railway/Render — no local install needed) | |

If you use `pyenv` or `nvm`, they'll auto-detect the pinned versions above when you `cd` into the project.

## First-Time Setup (do this once after cloning)

### 1. Backend

```bash
cd backend

# Use Python 3.12 specifically — check what you have first:
python3.12 --version

# If you don't have 3.12, see "Installing Python 3.12" below.

python3.12 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

Create your `.env` file (copy the example and fill in real values):
```bash
cp .env.example .env
```
Ask a backend lead for the real `DATABASE_URL`, `RAZORPAY_KEY_ID`, etc. — never commit real secrets to the repo.

### 2. Frontend

```bash
cd frontend
npm install
cp .env.example .env
```

### 3. Run both (two separate terminals)

```bash
# Terminal 1
cd backend && source venv/bin/activate && uvicorn app.main:app --reload

# Terminal 2
cd frontend && npm run dev
```

Frontend: http://localhost:5173
Backend docs (auto-generated by FastAPI): http://localhost:8000/docs

## Installing Python 3.12 (if you don't have it)

**Windows (WSL/Ubuntu):**
```bash
sudo apt update
sudo apt install software-properties-common -y
sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt update
sudo apt install python3.12 python3.12-venv -y
```

**Mac:**
```bash
brew install python@3.12
```

## Common Setup Issues (already solved once — don't re-debug these)

| Error | Fix |
|---|---|
| `npx tailwindcss init -p` fails ("could not determine executable") | Tailwind v4 removed this command. Use `npm install -D @tailwindcss/vite` and add the plugin to `vite.config.js` instead. No config file needed — see `frontend/src/styles/index.css` which just has `@import "tailwindcss";` |
| `psycopg2-binary` build fails ("pg_config not found") | You're on Python 3.13+/3.14, which lacks a wheel for the pinned version. Fix: use Python 3.12 (see above) — `requirements.txt` is already pinned to versions that work on 3.12. |
| `pandas` build hangs/fails | Same root cause — Python 3.12 fixes it. |
| `ModuleNotFoundError: No module named 'pkg_resources'` | `setuptools` 82+ removed it. Already pinned in `requirements.txt` (`setuptools<82`) — just re-run `pip install -r requirements.txt`. |
| `source venv/bin/activate: No such file or directory` | You skipped `python3.12 -m venv venv` — the venv folder doesn't exist yet. Run that first. |

If you hit something not on this list, check with the team before spending hours debugging — someone may have already solved it.

## Branching / Git Workflow

- `main` — stable, working code only
- Create a branch per feature: `git checkout -b feature/product-listing`
- Open a PR before merging into `main` — at least one other teammate reviews
- Never commit `.env` files (already in `.gitignore`) — real secrets stay local or get shared privately
